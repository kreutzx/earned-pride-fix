# One Line of Earned Pride

A one-line entry for the make.fun bounty "One Line of Earned Pride": after 11 years of night shifts, Nurse Sari paints her own name on the clinic door, in gold. The entrypoint writes the fixed line verbatim to `entry.txt`.

Run it with:

```bash
python3 main.py
```
